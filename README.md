# Plate Hunter v2

Игра про автомобильные номера для Telegram Mini App. Сервер без внешних зависимостей (нужен только Node.js 18+).

## Структура
- `packs/ru.json` — российский пак: алфавит, регионы, правила очков, редкость, цены. Новая страна (DLC) — новый файл в этой папке.
- `server/engine.js` — генерация и оценка номеров по правилам пака.
- `server/server.js` — API (`/api/state`, `/spin`, `/sell`, `/keep`, `/sell-garage`), раздача страницы.
- `server/verify.js` — проверка подписи Telegram `initData`.
- `web/index.html` — игра (фронтенд).
- `tools/simulate.js` — симуляция баланса; `tools/test.js` — автотест.

## Локальный запуск (без Telegram)
```
npm run simulate        # баланс на миллион круток
npm test                # автотесты
DEV_MODE=1 npm start    # откройте http://localhost:3000
```
`DEV_MODE=1` разрешает вход без Telegram. На боевом сервере его включать нельзя.

## Публикация (Render, один сервис)
1. Загрузите папку проекта в репозиторий GitHub (без `data/`).
2. На render.com: New → Web Service → ваш репозиторий. Build Command: пусто. Start Command: `npm start`.
3. В Environment добавьте `BOT_TOKEN` (токен от @BotFather). `DEV_MODE` не добавляйте.
4. Получите адрес вида `https://имя.onrender.com` и проверьте, что он открывается по `https://`.
5. В @BotFather: `/newapp` (или `/setmenubutton`) и вставьте этот адрес.

Внимание: на бесплатных тарифах диск часто сбрасывается при перезапуске, и файл `data/db.json` теряется. Для настоящей игры подключите постоянный диск или PostgreSQL (замените функции `save` и `player` в `server.js`).

## Как добавить DLC с иностранными номерами
1. Скопируйте `packs/ru.json` в `packs/de.json`, поменяйте `id`, алфавит, регионы, правила и цены.
2. Если нужен новый тип правила, добавьте проверку в `CHECKS` в `engine.js`.
3. Формат номера (сейчас «буква-цифры-две буквы + регион») для других стран потребует расширения `generate` и `plateText`.
4. Выдачу пака игрокам (покупка за Telegram Stars) добавьте в `server.js`: сейчас активен один пак, `ACTIVE_PACK`.

## Настройка баланса
Правила и пороги лежат в `packs/ru.json`, а цена крутки и размер гаража в `CFG` в `server.js`. После правок запускайте `npm run simulate`: ориентир возврата 75-90%, распределение редкости около 80/14/3/2/0,1%.
